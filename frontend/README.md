# SmartHire Frontend

React + Vite frontend starter for the SmartHire resume analyzer and job matcher.

## Run locally

```powershell
cd frontend
npm install
npm run dev
```

Open the URL Vite prints, typically `http://localhost:5173`.

## Build check

```powershell
npm run build
```

## Included screens

- Marketing landing page
- Login and signup with Candidate / Recruiter role selection (frontend demo only)
- Candidate dashboard
- Resume upload UI with file type and size validation
- Resume analysis preview
- Job matches, job detail, save-job interaction
- Application tracking
- AI assistant demo chat
- Recruiter dashboard and candidate management
- Responsive sidebar and mobile navigation

## Important

This is a frontend prototype. Authentication, resume parsing, real AI analysis, database persistence, job APIs, and real application submission are not connected yet. Sample scores and jobs are illustrative. No resume file is uploaded to a server by this frontend alone.
